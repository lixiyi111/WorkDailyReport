# 用例模板：生成个人日报（UC5）

| 项目 | 内容 |
|------|------|
| 用例编号 | UC5 |
| 用例名称 | 生成个人日报 |
| 参与者 | 定时任务（主）、成员（查看 / 编辑） |
| 关联需求 | S5、IR-2、IR-3、IR-4、IR-5、IR-6 |
| 前置条件 | 成员与身份映射已配置；GitHub / 飞书凭证有效（或允许降级） |
| 触发条件 | 每日 18:30 定时触发，或组长在 Web 端手动触发 |

## 主流程

1. 编排器加载当天处于启用状态的成员；
2. 采集层并行拉取 GitHub 提交、飞书任务、飞书群消息；
3. 规范化并按自然键去重，写入原始数据表；
4. 身份解析器把原始记录映射到成员，未命中写入 `identity_unmatched`；
5. 归属引擎按角色（author / reviewer / owner / participant）生成归属条目；
6. 个人日报生成器按任务 / 模块归类，输出「今日完成 / 协作贡献 / 问题与阻塞 / 明日计划」；
7. 日报与条目写入数据库，状态置为 `generated`。

## 异常流程

- **身份未映射**：保留数据并标记「未归属」，日报中提示组长绑定；
- **成员当天无数据**：输出「无产出」，不空白、不报错；
- **请假 / 节假日**：标注状态，不计为异常；
- **数据源失效**：降级为部分生成，团队日报标注缺失数据源。

## 后置条件

- 每个有数据的成员生成一份个人日报；
- 每条日报条目可回溯到原始数据 ID；
- 重复执行同一日期不产生重复条目。

## 验收要点

对应 proposal 的 F4、B1、B2、B3、B6。
