## 1. 变更背景

当前 v2 已覆盖 `S1–S9`：GitHub 提交、飞书任务、飞书消息采集，个人/团队日报，邮件/飞书/控制台推送，MySQL 存储与 Web 查看编辑。

本次变更只做一件事：**新增飞书考勤数据采集**，并把考勤纳入个人日报与团队日报。目的是验证「需求变更 → 规范同步 → 代码实现 → 全量回归」的变更涟漪能力。

## 2. 变更内容

### 2.1 新增需求

| 编号 | 内容 |
|------|------|
| **S10** | 采集飞书考勤：按日期、成员采集上下班打卡状态（正常 / 迟到 / 早退 / 缺勤 / 请假 / 节假日），字段含成员、日期、状态、上班时间、下班时间、来源 ID |
| **IR-11** | 考勤必须按「成员 + 日期」幂等：同一成员同一天只保留一条记录；重复采集不重复计数 |
| **F9** | 指定日期、指定成员的考勤字段完整率 100%；无记录时明确输出「无考勤记录」，不空白、不报错 |
| **F10** | 个人日报新增「考勤」段；团队日报新增考勤汇总（正常 / 迟到 / 请假 / 缺勤计数） |
| **B2（更新）** | 请假、节假日单独标注，不计为异常；缺勤与「没有采集到」区分开 |

### 2.2 明确不做

- 不做考勤审批流、排班管理、加班规则；
- 不做考勤数据的人工补录 UI（只做采集与展示）；
- 不改变现有 `S1–S9` 的字段与接口语义。

## 4. 数据模型

新增 `attendance_records`：

```sql
CREATE TABLE attendance_records (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  member_id BIGINT UNSIGNED NOT NULL,
  attendance_date DATE NOT NULL,
  status VARCHAR(16) NOT NULL,          -- normal/late/early/absent/leave/holiday
  check_in_at DATETIME NULL,
  check_out_at DATETIME NULL,
  source VARCHAR(32) NOT NULL DEFAULT 'feishu',
  source_id VARCHAR(128) NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_attendance_member_date (member_id, attendance_date),
  KEY idx_attendance_date (attendance_date),
  CONSTRAINT fk_attendance_member FOREIGN KEY (member_id) REFERENCES members(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

约束：
- **幂等键**：`(member_id, attendance_date)`；
- 同一成员同一天多条打卡记录在采集层聚合成一条日记录；
- 原始打卡明细不落库，只保留日报需要的状态与首末时间。

## 5. 接口契约

```python
@dataclass(frozen=True)
class AttendanceRecord:
    member_external_id: str
    attendance_date: date
    status: str                  # normal / late / early / absent / leave / holiday
    check_in_at: datetime | None
    check_out_at: datetime | None
    source_id: str | None = None

class FeishuAttendanceCollector:
    source = "feishu_attendance"
    async def collect(self, window: TimeWindow) -> CollectionResult[AttendanceRecord]: ...
```

- 真实模式：调用飞书考勤接口（`/open-apis/attendance/v1/user_tasks/query`），失败按现有 `partial + SourceError` 降级；
- Mock 模式：`MockAttendanceCollector` 按成员生成确定性考勤，至少覆盖正常 / 迟到 / 请假三种状态；
- 身份解析：用 `member_identities`（provider=`feishu`）映射到成员；未命中写 `identity_unmatched`。

日报生成签名扩展：

```python
PersonalReportGenerator.generate(..., attendance: AttendanceRecord | None = None)
TeamReportGenerator.generate(..., attendance_by_member: dict[int, AttendanceRecord] | None = None)
```

新增接口：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/attendance?date=YYYY-MM-DD` | 查询考勤；member 只能看本人 |

## 6. 日报模板变化

个人日报由四段式变为五段式：

```
## 今日完成
## 协作贡献
## 考勤
- 状态：正常
- 上班：09:01
- 下班：18:30
## 问题与阻塞
## 明日计划
```

无记录时：

```
## 考勤
- 无考勤记录
```

团队日报「团队概览」增加一行：

```
- 考勤：正常 8 · 迟到 1 · 请假 1 · 缺勤 0
```
